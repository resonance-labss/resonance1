The brand page lists the palette #a9ddd3, #e8e3d5 and #010101; its dark variant above colours the symbol #BBEBE1.

`output/selection/brand/rialo-symbol.svg` is the same path as rialo-symbol-on-cream.svg, without the background square,
with the viewBox cropped to the symbol (41.0986 37 96.8036 106) and the dark-variant colour #BBEBE1. The path data is
identical character for character; `output/selection/rialo-mark.test.cjs` checks this and renders both to compare.

Note: `https://www.rialo.io/images/rialo-logo.svg` (the small icon in Rialo's site header) is a different drawing and
is not used here.
